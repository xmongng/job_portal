# API Contract

Base path dự kiến: `/api`.

| Area | Resource prefix |
|---|---|
| Auth | `/auth` |
| Companies | `/companies` |
| Jobs | `/jobs` |
| Applicant profile/CV | `/applicants`, `/resumes` |
| Applications | `/applications` |
| Interviews | `/interviews` |
| Offers | `/offers` |
| Recommendation/AI | `/recommendations`, `/ai` |
| Reports/Audit | `/reports`, `/audit-logs` |
| Notifications | `/notifications` |

OpenAPI sẽ là source of truth khi bắt đầu triển khai Express router.
